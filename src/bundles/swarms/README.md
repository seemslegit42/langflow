# lfx-swarms

`lfx-swarms` is the standalone Langflow extension that provides Swarms components.

It is installed by the full `langflow` distribution. Users of `lfx` or
`langflow-base` can opt in with the compatibility extras:

```bash
uv pip install "lfx[swarms]"
uv pip install "langflow-base[swarms]"
```
